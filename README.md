# Retr0_to0l_Rp1

Легковесный веб-интерфейс для аудита Wi-Fi сетей и перехвата WPA/WPA2 Handshake. 
Оптимизирован для работы на маломощных устройствах (например, Raspberry Pi Zero W) под управлением Kali Linux.

## Возможности

- Перевод Wi-Fi адаптера в режим монитора (Monitor Mode) через веб-интерфейс.
- Сканирование эфира: поиск точек доступа и подключенных клиентов.
- Автоматический захват Handshake с отправкой деаутентификации.
- Проверка валидности пойманного хендшейка через `wpaclean`.
- Сохранение дампов в папку `hs/`.

## Требования

- **ОС:** Linux (Kali Linux, Debian, Ubuntu).
- **Оборудование:** Wi-Fi адаптер с поддержкой режима монитора.
- **Права:** Запуск строго от имени `root` (требуется для работы с сетевыми интерфейсами).
- **Системные пакеты:** `aircrack-ng`, `iw`.

## Установка

1. Клонируй репозиторий:
   ```bash
   git clone https://github.com/Luc1ferLan1us/Retr0_to0l_Rp1.git
   cd Retr0_to0l_Rp1
```
2. Установи системные зависимости:
	```sudo apt update
	sudo apt install aircrack-ng iw python3-pip -y
```
3. Установи Python-библиотеки:
	```pip3 install -r requirements.txt```

## Использование

Запусти сервер:
	```sudo python3 app.py```

Открой в браузере http://127.0.0.1:5000 (или http://<IP-адрес_устройства>:5000, если запускаешь с другого устройства).

Порядок действий:

1. Нажми "Обновить список" и выбери свой Wi-Fi интерфейс.

2. Кликни по нему, чтобы перевести в режим монитора.

3. Нажми "Сканировать сети" и подожди 10 секунд.

4. Выбери нужную сеть из таблицы (BSSID и канал заполнятся сами).

5. Нажми "Запуск". Программа начнет отправлять деауты и слушать хендшейк.

6. Готовый .cap файл появится в папке hs/.
